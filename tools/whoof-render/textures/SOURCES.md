# Texture sources

Offline scene materials use Poly Haven's `wood_table_001` and `denim_fabric_03`, downloaded through the public asset API on 2026-10-10.

- https://polyhaven.com/a/wood_table_001
- https://polyhaven.com/a/denim_fabric_03
- License: CC0, https://polyhaven.com/license
- Files: 2K JPEG diffuse, roughness and OpenGL normal maps. Gray material tint is applied in the shader; original downloads are retained unchanged.
- These source textures are build inputs, not initial browser downloads.
